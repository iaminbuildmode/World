# Lebas Elementor Suite

Custom Elementor Pro widgets for the Lebas storefront, packaging the existing
front-end HTML/CSS/JS (header, footer, product card, 3-column gateway,
editorial landing, price tag, size concierge bottom sheet, restock alert,
designer directory, smart size guide, packaging selector, cart urgency bar)
into reusable widgets under the **"ویجت‌های اختصاصی لـبـاس"** category.

## Requirements
- WordPress 6.7+
- Elementor 4.x
- Elementor Pro 4.x
- WooCommerce 9.x+

## Install
Copy `lebas-elementor-suite/` into `wp-content/plugins/` and activate.
Activate `lebas-luxury-child` theme for fonts/design tokens.
